# Hyperland Dotfiles

This project was made with the help ai AI.

This is the theme I use daily on my own computer. It wa made for a laptop for a 1920x1200 resolution so some stuff might need some adjustments depending on your resolution and screen format.

The screen configuration is placed in `hypr/modules/monitors.lua` file. I left it on the repo so you have a base to create your own with your own screens settings.

Keyboard settings are in `hypr/modules/inputs.lua` file. By default it uses a en-gb layout, since I have external keyboards with diferent layouts I left the specific configs here too.

If you don't want to use mpvpaper remove it from `hypr/modules/autostart.lua`.

Requirements :

- Hyperland (of course)
- kitty (or any terminal you want, just make sure to not install kitty files if oyu don't use it)
- swaync
- thunar (filemanager)
- waybar
- wlogout
- wofi
- Jetbrains font
